# FIXED
Clash now loads blackbox functions using the same package databases and package flags (e.g. `-package`, `-package-id`, `-hide-package`, and the package environment) as the design itself. Previously, only `-package-db` flags were taken into account, so blackbox functions could not be loaded from hidden packages exposed with `-package` or `-package-id`.

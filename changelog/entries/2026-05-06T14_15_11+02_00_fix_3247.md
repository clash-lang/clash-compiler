# CHANGED
The unfoldable primitives in `Clash.Sized.Internal.{BitVector,Signed,Unsigned,Index}` now throw `XException` instead of `ErrorCall` on illegal input
(negative shift/rotate amounts on `BitVector`/`Signed`/`Unsigned`, out-of-range index/replaceBit on `BitVector`, and a negative result from `Index.minus`).
This restores the original design intent that Clash-defined primitives throw `XException` and aligns them with the rest of the `Sized` API.
User code that relied on catching `ErrorCall` from these specific operations will need to catch `XException` (or a parent like `SomeException`).

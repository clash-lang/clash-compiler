# ADDED
`clash --server`: a long-lived Clash process that compiles designs on request, one JSON document per line on standard input and output, keeping GHC's session, interface cache, plugins and compiled primitives warm between designs. A small design compiles in about half the time of a fresh `clash` process. `clash-testsuite` uses a pool of such workers with `--clash-server`.

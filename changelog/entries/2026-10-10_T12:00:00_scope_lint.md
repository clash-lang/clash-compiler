# ADDED
The new flag `-fclash-debug-invariants-shadowing` implies `-fclash-debug-invariants`, and additionally checks that the input of normalization, and the result of every transformation, is well-scoped: every local variable, including the type variables in types, is bound, every global variable exists, no transformation introduces binders that shadow a variable in scope, and no transformation introduces local binders with the unique of a global binder. Clash does not maintain these invariants yet, so this flag is meant for developing transformations.
